# idea 设计索引（Design Index）

> 本文件把 `idea/` 目录里的设计文档（重点 idea3/4/5/6）**逐小节**整理成索引，给每条一个**状态标签**。
> 目的是把「设计参考」和「开发待办」分开：**绝大多数条目默认是「📚 素材参考」，不逼你现在决定**。
> 当你想推进某条，把它升格为「🔜 定案远期 / ✅ 定案近期」并挪进 `roadmap.md`，或按 `AGENTS.md` 流程开始实现。

## 状态图例

| 标签 | 含义 | 说明 |
|---|---|---|
| 📚 素材参考 | 默认状态 | 先存着，以后再看；**不用现在做决定** |
| 🔜 定案远期 | 确定要做 | 但优先级低/依赖后期章节，暂时不开发 |
| ✅ 定案近期 | 确定要做 | 近期可开发（升格后应同步进 roadmap.md） |
| 💭 讨论中 | 想法未定 | 可行性/方案还没定，需要再想 |
| 🚫 弃案 | 明确不做 | 已决定不使用，仅归档备查 |

> **使用方式**：默认全是 📚。你（或 AI 协助）想推进某条时，把标签改成 🔜/✅ 并在备注里写一句"为什么/何时做"。想放弃的标 🚫。其余保持 📚 不动。
