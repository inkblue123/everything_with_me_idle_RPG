# glossary.md — 领域词汇表

> 只收"在这个项目里被赋予特定含义"的词，写含义不写实现。
> 新增/修改术语时同步 `docs/SPEC.md` 用词；同一概念不要出现两种叫法。

## 生活技能

**生活技能**：除战斗之外、玩家在特定地点执行的技能。分两类：探索采集（伐木 / 钓鱼 / 挖矿 / 采集 / 潜水 / 考古 / 探索）与原料处理（合成制造 / 烹饪 / 锻造 / 炼丹 / 药浴 / 雕刻 / 炼金术）。

**生活技能位序**：地点用一串固定顺序的标记表示「此地能执行哪些生活技能」，顺序恒为 伐木 / 钓鱼 / 挖矿 / 采集 / 潜水 / 考古 / 探索。改顺序要同步所有按位读取的地方。

**解锁**：生活技能先要拿到「解锁」才能出现在界面上。挖矿的解锁来自铁匠铺的力量测试。

## 挖矿

**挖矿**：从矿层中开采石料与矿石的生活技能。

**挖矿力**：玩家一次挖掘造成的伤害量。先被矿层的防御削减，剩余部分才扣矿层的生命。

**矿层**：可开采的资源对象，有生命、防御与掉落表。当前四种：碎石岩层、坚硬山岩、铁矿山石、硬冷岩层。**矿层**指"这一类可挖的东西"，**矿石**指挖出来的产物。

**矿点**：一个地点能刷哪些矿层、各自权重多少的地点级配置。

**矿石稀有度**：矿层实例刷新时随机到的档位（普通 / 稀有 / 特殊 1 / 特殊 2），决定属性补正与掉落表，**不直接告诉玩家**。

**找矿冷却**：一块矿挖完后，到下一块矿出现之间的等待时间（现为 10 秒）。

**挖矿专精**：记录挖矿经验的生活技能，0~10 级。本期只升级，不提供属性效果。

**刷矿 / 复活**：地点里的矿层被挖掉后，按该地点的复活时间重新抽一块。与"找矿冷却"不是一回事：前者是地点级定时刷新，后者是玩家视角的等待。

## 地图

**区域**：地图的分页单位，例如 村庄 / 村外后山 / 村外后山洞穴。

**洞内地图**：`backhill_cave` 区域的地图页，节点是洞内地点，连线是可通行关系。

**洞口节点**：同时出现在两张区域地图上的地点——洞穴入口既画在后山地图上，也画在洞内地图上。这是跨区域的正常登记方式，不是重复。

## 通用

**图鉴点亮**：首次获得某物品即自动记录一次，用于配方"集齐材料自动解锁"与图鉴展示；不需要专门为某个系统接线。
