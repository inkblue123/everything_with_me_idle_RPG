# A4 · 第三方砝码（薛尊 / 谭梦华 / 机明辉把降神拖垮）

- **一句话核心**：降神在绝境中再次强征虚空魔法师、再利用封印强者，结果把本来中立的第三方一个个推到对立面——他们不帮帝国，他们只是先被降神惹了。
- **适用轴**：A 战争结局

## 具体事件链

1. 降神为了补战力，重启**强制转化虚空魔法师**与**挖掘封印沉睡强者**的计划（都是已有设定，`idea8:L2453-2466`、`L2429-2436`）。
2. 薛尊的新虚空族被重点打击（降神最缺虚空核心，正是他们的命脉）→ 薛尊反击，专打降神的**后勤、传送节点、虚空1型据点**（`idea8:L2441`）。
3. 神谕站号称"自体循环"，但仍需要地表与天外的关键物资；链条被切断后，降神高空优势变成高空孤岛。
4. 谭梦华被两边当工具用（帝国想夺舍取功法，降神想让她当刀子），最后她选择"谁挡我延寿就打谁"，在降神一次大会战的关键时刻反手——降神阵线崩掉一角。
5. 机明辉（可选）在降神试图回收磁浮密林资源时出手，把降神一支采集队连同重型装置一起抹掉。
6. 帝国顺势收网，接管极顶高原。战后帝国把这三人与浅绿并列为"四大恶贼"——**正是因为他们确实各自捅了降神一刀**（`idea9:L13-84`、`L270-277`）。

## 机制
- 新虚空族天然无法被推算追踪（`idea8:L2440`），最适合打后勤与节点。
- 谭梦华的界心花"不能移动但主场无敌"，放在关键战役的咽喉位置就是一道关不掉的闸门。
- 原文明确留了口子：**"但如果新虚空族想要参与神帝战争，那结果就不好说了"**（`idea8:L2444`）。

## 谁付出代价
- 帝国：坐收渔利，但也因此**欠了战后收拾三个麻烦的账**（这正是 idea9 破屏障篇的来源）。
- 薛尊：彻底成为帝国通缉对象。
- 谭梦华：出手即暴露，寿命与双魂问题进一步恶化。

## 新埋的伏笔
- 三人之间的**关系与默契**（他们后来在破屏障篇会各自行动，此处的交集是前提）。
- 帝国对三人的忌惮 → 战后围剿名单的形成。

## 需要新增的设定
- 【待定】三人互动的程度：互不相识（各自为战）／间接配合／正式结盟。**建议各自为战**，保留后篇"四人从不同动机走到同一件事"的对称美感（`idea9:L13-84`）。

- 戏份被第三方分走，主角线更边缘。
