# 方案卡（Option Cards）

> 用途：把"剧情往哪走"变成**可挑选、可组合、可验算**的卡片。
> 一个方案一张卡，互斥的方案并列摆出；被选中的卡挪进 `_已采用/`，并在卡顶写上定案日期与理由。

## 一、卡片模板

```
# 编号 · 标题
- 一句话核心：
- 适用轴：
- 具体事件链：1) … 2) … 3) …（这是可以直接改写成正文的骨架）
- 机制（为什么会这样）：必须是世界观里已经存在的规则或已埋的伏笔
- 谁付出代价：（不能有免费午餐）
- 回收的伏笔：填 04_伏笔台账.md 的编号
- 新埋的伏笔：
- 需要新增的设定：→ 事后补进 01_故事圣经.md / 03_战力标尺.md
- 对 idea9 的兼容性自检：（逐条对照 02_年表.md 的【硬约束】）
- 风险 / 副作用：
- 适合搭配：
```
