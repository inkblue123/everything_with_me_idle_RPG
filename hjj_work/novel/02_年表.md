## 天外入侵
- **第一次进攻**：紫色传送通道 + 树根状物体；降神靠葬星渊研究与战争部门调度转胜。`idea8:L1518-1539`
- **战后秘密共识**：帝国得情报，降神得薪火秘境分部与帝国人力物力。`idea8:L1541-1544`
- **第二次进攻**：天外生物数量近乎无限、战术化；人族无法远行虚空只能挨打。`idea8:L1546-1565`
  - 支线：葬星渊—寂灭黑域通道战役（源头是浅绿当年修补的神帝中枢传送门）。`idea8:L1570-1586`
  - 转折：尸骸排开虚空 → 虚空压制减弱 → 帝国魔法解放。`idea8:L1588-1605`
  - 翻盘：薪火秘境大批投运 + 星航部门研出虚空航行技术（刺杀队打老巢）。`idea8:L1608-1631`
- **机明辉复活**，凝**生命晶核**，裹超巨型元素风暴打退天外生物，与帝皇两不相胜，退居磁浮密林。`idea8:L1668-1687`
- **噬魔怪入侵（后期）**：天外生物内部决议大部分撤离、少数噬魔怪留下死斗（人族不知情）。`idea8:L2125-2133`
  - 噬魔怪吸收魔力滚雪球破防线；**陆岩**参战、击杀首领；陆岩把首领打穿天外屏障、一路打到**帝国首都**，被赦免封为功臣。`idea8:L2174-2239`
  - 遗留：**天外屏障的大洞**（陆岩打穿处）、磁浮密林元素风暴、被封印的噬魔装甲、葬星渊的传送通道。`idea8:L2234`、`idea8:L2243`

## 神帝战争
- **导火索**：打完天外入侵后战果分配谈崩；**深层原因是帝国主动开战**——帝皇清楚"两大组织若各自和平发展，帝国内部会先出隐患与内斗"，于是要把世界带回他擅长的乱世。`idea8:L2242-2246`、`idea8:L2294`、`[Q4]`
- **前期**：降神宗师强于帝国宗师，攻城拔寨、还打下几个薪火秘境节点；战线拉长后后勤缺陷显现 → 进入消耗战。`idea8:L2347-2354`
- **中期**（已写）：
  - **天恒汲灵阵**（L2358-2411）：薪火秘境匿名机制中流出的神秘阵法，被帝国改造成抽取屏障能量 → 战局从不利变持平。作者身份查不到（追查指向**司徒明**，断线）。
  - **薛尊与新虚空族**（L2413-2444）：虚空魔法师受歧视与强征 → 薛尊带众独立，偷袭虚空 1型据点，双方战力流失。
  - **界心花战役**（L2446-2505）：降神复活封印强者，谭梦华最强；她为找血源血大闹血渊、深入帝国中计 → 帝国数位宗师围攻 → 魂道宗师夺舍反被反噬 → 双魂。两侧损失惨重，战线停顿。
- **时长**：约 8~15 年（前期 2~3 年、消耗战 4~6 年、收尾 2~3 年）。`[Q1]`
- **规模**：全面战争。两大势力都能在全球范围作战，多处同时开战，按战役结果决定是否继续增兵；局部拉锯后双方大量投入、升级为特大战役（界心花战役即样例）。`[Q2]`、`[Q3]`
- **全局最大的战役**：发生在后来成为"**神帝战争废墟**"（中世界第二大大陆）的那片陆地上，过程待设计。`[Q3]`
- **后期**：草稿见 `novel/08_草稿/神帝战争后期_v1.md`（停滞 → 帝国的赌局 → 天恒汲灵阵铺开 → 降神困局 → 浅绿判断 → 浅榕转折之战 → 浅绿直面浅榕 → 浅榕改道与失败 → 战争加速 → 决定性大战 → 降神台陷落 → 战后）
- **【已定案】降神的败因不是内部分裂**：高层统一，"战不胜就保存未来"是共识；**降神台被帝国攻破**，神谕站载着核心力量撤离星球只是暂避锋芒（能在虚空长期存活的原因：神谕站久居虚空 + 天外入侵新材料 + 浅绿留下的虚空研究完成 0→1 突破）。`[Q36]`、`[Q37]`
- **败相时点**：界心花战役之后、**另一场有浅榕参与的大战**之后。`[Q35]`

## 破坏天外屏障（idea9 开篇）
- 【硬约束】降神战败；不愿投降者**操纵神谕站飞离**，原位留下大洞。`idea9:L3-4`
- 【硬约束】帝国瓜分降神总部遗产，宣布"屏障不可破坏"，占领极顶高原。`idea9:L5-10`
- 屏障此前已被削弱：机明辉元素风暴洞穿处、陆岩打穿处、战争中天恒汲灵阵大规模抽取。`idea9:L6-9`
- 四方同时动手：浅绿（镇虚峰连环爆炸）、机明辉（收集光/雷元素）、薛尊（在混合区取虚空核心）、谭梦华（取血源血）。`idea9:L13-150`
- 结果：屏障不可逆崩解；虚空降临未发生；地表魔力暴涨；屏障碎片凝成彗星被吹离。`idea9:L126-141`
