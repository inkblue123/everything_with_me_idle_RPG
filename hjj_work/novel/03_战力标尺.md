# 战力标尺（Power-scaling Bible）

> 本书**没有统一数值**，境界以"能发挥出的最强战力表现"衡量，且从未更新标准。`idea8:L147-176`
> 所以本表不写数字，只写**档位 + 锚点人物 + 环境修正**。写战斗时先查表：谁在哪档、在什么环境下加减。

## 一、档位

| 档 | 名称 | 锚点 | 说明 |
|---|---|---|---|
| T0 | 凡人修为 | 浅绿（**对外公开身份**） | 真实实力远不止此，但这是帝国情报对她的判定 |
| T1 | 普通修士 | 各领主麾下士兵、秘境大弟子 | |
| T2 | 领主级 / 精锐 | 血渊五领主、玄盟林震渊 | 帝国的"注水宗师"多落在此档 |
| T3 | 高手 | 各势力骨干、天外生物精英 | |
| T4 | **宗师** | 降神 17 宗师、帝国真宗师、谭梦华（复活后恢复到宗师） | 帝国宗师一般弱于降神宗师；帝国宗师受环境魔力影响极大 |
| T5 | 宗师顶点 / 爆发态 | 陆岩（星界装甲增幅）、机明辉（元素风暴内）、谭梦华（界心花全开）、噬魔怪首领（吸收态） | 需要**特定条件**才能达到，条件一撤就回落 |
| T6 | 至尊【待定】 | 仅 `idea9:L7` 出现一次 | 需你拍板：删掉，还是新设一档 |
| T7 | 神明级手段 | 传承空间、创世光墙、天外屏障、天选之人权柄 | 不可对抗，只能利用规则 |

## 二、环境修正（写战斗前必查）

| 环境 | 效果 | 谁吃亏 |
|---|---|---|
| 起源星地表（魔力正常） | 魔法正常发挥 | — |
| 起源星地表（魔力**上升期**） | 魔法修炼者变强——帝国胜降神的隐藏原因 | 降神 |
| 天外虚空 | 虚空压制传统元素；魔法与灵魂被撕扯 | 帝国（浅绿除外） |
| 葬星渊 | 空间稳固、移动减速、远程被削、**近战为王** | 远程与传送手段 |
| 血渊 | **全区排斥虚空**，虚空入内即爆/被抹杀 | 虚空魔法师、薛尊部众 |
| 机明辉元素风暴内 | 元素手段极大增幅，但**限制收集范围** | 近身者；机明辉自己被范围困住 |
| 创世光墙外围 | 瓦解一切脱离实物之物，须收敛全部修为与神识才能停留 | 所有高手；虚空魔法师除外 |
| 创世光墙内部 | 九色光柱反击，瓦解一切 | 一切存在，虚空也不例外 |
| 天恒汲灵阵覆盖区 | 能量可被抽走、可自修复、可给装置供能 | 依赖环境魔力的守方 |
| 帝国皇宫 | 集结大量宝物与宗师手段，帝皇在此可压过降神宗师 | 只对帝皇本人有效；也把他锁在皇宫里 |
| 机明辉的"死亡之地" | 生命晶核造出的绝地，全盛期高手都难以通过 | 一切常规防御与修为；**唯真源血的百毒不侵可肉身穿过**（`[Q15]`） |

| **帝皇** | T4 顶尖（**皇宫内 T4+，可压降神宗师**） | 皇宫内集结大量宝物与宗师手段；帝国顶尖魔法修行者 | 实力已许久没有变化；**被皇宫限制、不能外出**；治理帝国疏忽了修行 |

## 四、使用规则

1. 每次让某个角色"打得过/打不过"时，必须能说出他属于哪档、当前环境修正是什么。
2. 任何 T5 的出现都要有**条件**，且条件必须可被剧情剥夺。
3. **不允许**为了让某场戏好看而临时提高某一档——如果必须提高，先在 `01_故事圣经.md` 里登记新设定，再回来改本表。

> **宗师稀缺感没有硬标准**：一场战役死几位宗师、帝国上百名"宗师"里真能打的占几成，均**按剧情需要安排**（`[Q27]`、`[Q28]`）。
> 但**同一段剧情内部必须自洽**：这一段把宗师写得稀缺，下一段就不能随便死一片；如有调整，回来改本表。
